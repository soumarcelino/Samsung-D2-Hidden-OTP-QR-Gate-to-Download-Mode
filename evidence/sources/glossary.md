# 10. Glossário

- **ABL:** Android Bootloader, implementação UEFI usada no SoC Qualcomm.
- **ADB:** Android Debug Bridge.
- **AT command:** comando textual usado por interfaces de modem/diagnóstico.
- **Binder:** IPC principal do Android.
- **D2:** erro/estado de lockdown associado à tentativa de abrir Odin Mode.
- **DMC:** nome do serviço/política e do vault lógico investigado.
- **HAL:** Hardware Abstraction Layer.
- **Maintenance Mode:** modo Samsung que isola dados durante assistência técnica.
- **Odin Mode:** modo de download/flash de dispositivos Samsung.
- **QSEECom:** interface de comunicação com aplicações confiáveis no TEE Qualcomm.
- **RPMB:** Replay Protected Memory Block, armazenamento autenticado comum em arquiteturas seguras.
- **TA:** Trusted Application executada no TEE.
- **TEE:** Trusted Execution Environment.
- **VaultKeeper:** serviço Samsung para gerenciamento de vaults apoiados pelo ambiente seguro.
